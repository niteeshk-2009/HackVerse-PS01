## 1. Executive Summary & Problem Context
India's retail investment landscape has exploded: **130 million retail demat accounts added in 4 years**, with **80% under the age of 30**. However, SEBI's official 2024 study confirms that **89% of individual retail F&O participants lose money**, with collective net losses exceeding ₹52,000 Crores.

This tragedy is **not a data scarcity problem**. NSE real-time feeds, SEBI LODR corporate disclosures, and quarterly earnings call transcripts are publicly accessible. It is an **infrastructure and decision-intelligence asymmetry**:
- Institutional hedge funds deploy parallel multi-analyst teams running quantitative momentum, balance sheet forensics, FII order flow tracking, and macro modeling simultaneously.
- A retail investor gets a raw price chart, social media FOMO, and ungrounded Telegram tips.

**SPIDER SENSE** bridges this gap. It is an autonomous multi-agent reasoning system that ingests market feeds, retrieves regulatory disclosures through semantic RAG, detects retail traps and agent disagreements, weights signals against the user's specific portfolio concentration, and renders an **inspectable, cited, personalized investment verdict in under 40 milliseconds**.

---

## 2. The Five Cardinal Questions Answered
Every single analysis generated by SPIDER SENSE answers:
1. **WHAT is happening?** Direct, unambiguous market diagnosis.
2. **WHY is it happening?** Causal reasoning across price, volume anomaly, and institutional flow.
3. **WHAT evidence supports it?** Verifiable citations from SEBI corporate filings with exact page/section provenance.
4. **HOW confident is the system?** Calibrated confidence with explicit disclosure of market uncertainties.
5. **WHAT does it mean for THIS investor?** Tailored capital guardrails, position caps, and suitability conditioned on investor risk profile.

## 4. The Specialized Agent Team
| Agent | Role | Data Ingestion | Output Contract & Responsibilities |
|---|---|---|---|
| **Market Spider** | Technical & Momentum Analyst | NSE price feeds, volume, moving averages, RSI-14, MACD, ATR, Beta | Evaluates 3 independent signal dimensions (Momentum, Volume Anomaly, Oscillators). Detects breakouts vs exhaustion. |
| **Fundamental Web** | Fundamental & Regulatory Analyst | SEBI LODR filings, Q2 FY26 earnings disclosures, debt covenants | Executes Semantic Vector RAG queries. Extracts factual excerpts with verifiable document page & section citations. |
| **Sentiment Spider** | Sentiment & Flow Analyst | FII/DII net flows, news sentiment, retail call chase index | Identifies "Retail Traps": flags divergences where retail traders chase momentum while smart money unwinds. |
| **Risk Guardian** | Portfolio & Behavioral Risk | User risk profile, existing holdings, sector allocation | Computes Herfindahl-Hirschman Index (HHI). Enforces capital preservation, position caps, and stop-loss bounds. |
| **The Web Mind** | Synthesis Orchestrator | Structured outputs from all 4 agents | Resolves cross-agent conflicts, applies profile weights, generates inspectable explanations, discloses uncertainty. |

## 5. Key Differentiators & PS-01 Compliance
- **Strict 3-State Data Policy**: Explicitly distinguishes between `LIVE DATA`, `DEMO DATA`, and `DATA UNAVAILABLE`. Never misrepresents demo data as live.
- **Multi-Dimensional Signal Classification**: Evaluates Price Momentum, Volume Anomaly, and Volatility/Oscillators with normalized scores (-100 to +100) and stated confidence.
- **Verifiable RAG Grounding**: Refuses ungrounded generation. Fundamental conclusions display the document title, section, and exact excerpt citation.
- **Demonstrable Personalization**: The *exact same market signal* (e.g. Tata Motors breakout) yields **"GRADUAL STAGGERED ACCUMULATION"** for a Conservative Investor vs **"MOMENTUM SWING OPPORTUNITY"** for an Aggressive Trader.
- **Cross-Agent Conflict Resolution**: Detects when technical momentum contradicts smart money selling; explicitly explains the resolution in the reasoning trace.
- **Degraded-Data Resilience**: Gracefully handles disconnected price streams (cached fallback with staleness warning) and missing regulatory filings (`DATA_UNAVAILABLE` status without hallucinating).
- **Session Telemetry & Persistence**: Tracks agent latency, signal confidence, portfolio HHI score, and cross-agent agreement across sessions in SQLite.
- **Head-to-Head Comparison Duel**: Side-by-side comparative analysis between any two equities evaluated through all 4 agents.
- **Spider-Verse Theming**: Minimalist switch toggle offering Peter Parker Dark Mode (black/red/cyan) and Gwen Stacy Light Mode (white/pink/purple).

## 6. Installation & Quick Start

### Prerequisites
- Python 3.10+ (Tested on Python 3.13)
- Modern web browser (Chrome, Edge, Firefox, Safari)

### Installation
```bash
# Clone the repository
git clone https://github.com/niteeshk-2009/HackVerse-PS01.git
cd HackVerse-PS01

# Install required dependencies
pip install -r requirements.txt
```

### Launch the Application
```bash
python run.py
```
Open **[http://localhost:8000](http://localhost:8000)** in your browser.  
Interactive API Documentation: **[http://localhost:8000/docs](http://localhost:8000/docs)**.

### Run Acceptance & End-to-End Tests
```bash
# Run acceptance test suite (all 10 requirements)
python -m tests.test_system

# Run end-to-end full pipeline verification
python -m tests.test_end_to_end
```
